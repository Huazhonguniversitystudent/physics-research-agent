# 60–90 秒 Demo 录屏脚本

## 录制前

- 设置 `PHYSICS_AGENT_PUBLIC_DEMO=1`，确认侧栏显示 Public Demo Mode。
- 关闭包含 `.env`、终端路径、真实 registry 和私人数据的窗口。
- 只使用 synthetic CSV、公开项目文档和公开 Mumax3 论文。
- 浏览器缩放保持 100%，先清空输入框；不录制 API Key 配置过程。

## 0–10 秒：项目首页

画面：Web 首页和侧栏。

旁白：“这是 Physics Research Agent，一个面向物理科研场景的可验证 AI Agent 原型。它把模型决策、Python 计算和文献证据分开。”

## 10–25 秒：数学 Tool Calling

操作：点击示例 2，运行 `12345 * 6789`，展开工具过程。

旁白：“模型没有心算，它请求 calculator，本地 Python 执行受限表达式，得到 83,810,205，再由模型组织答案。页面只显示简化参数和结果，不显示密钥或本机路径。”

## 25–45 秒：合成科研数据

操作：切换“科研数据 Demo”，点击运行。

旁白：“公开演示只读取 synthetic CSV。程序用相邻点线性插值计算两条曲线的首次过零时间，并绘制曲线。SYNTHETIC 标识强调这些数值不代表真实软件结果。”

## 45–65 秒：PDF RAG

操作：切换“论文问答”，询问默认动力学积分方法；展示 p12 引用与工具 trace。

旁白：“论文问题进入 PDF RAG。PyMuPDF 按页提取，TF-IDF 返回 Top-K 证据，答案引用真实 PDF 第 12 页。后端只接受本轮检索返回过的引用。”

## 65–80 秒：架构与 GitHub

画面：README 架构图、Evaluation 表。

旁白：“同一个 Agent 区分当前数据、项目文档和论文三类来源。仓库包含 113 项单测与独立 holdout，并如实保留负例误召回和文档改写命中下降。”

## 80–90 秒：总结

画面：回到首页。

旁白：“一句话总结：LLM 负责决策，Python 负责可靠执行，RAG 负责文档证据。这是学习原型，不替代科研判断。”

## 录制检查

- [ ] 没有出现真实 CSV、真实 PNG、私人 alias 或未发表数据
- [ ] 没有出现 API Key、`.env`、本机用户名或绝对路径
- [ ] 至少展示一次 Tool Trace 和一次 PDF 页码引用
- [ ] 合成数据始终可见 `SYNTHETIC`
- [ ] 总时长控制在 60–90 秒
