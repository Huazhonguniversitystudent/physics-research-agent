# Day 3：科研数据工具

## 为什么科研 Agent 不能只会聊天

科研问题常常依赖文件中的真实数值。让模型直接猜测“哪条曲线更早翻转”，无法保证它读过数据，也不能验证答案。Day 3 把任务分成两部分：模型决定需要什么工具，Python 读取 CSV、计算和绘图，模型再根据结果解释。

## CSV、pandas 和 DataFrame

CSV 是逗号分隔的文本表格：第一行通常是列名，后续每行是一条记录。例如 `time_ps,mz` 分别表示时间和磁化。

pandas 是 Python 的表格数据处理库。`pd.read_csv()` 把 CSV 读取为 DataFrame，后者可以理解成带列名和数据类型的二维表。我们用它查看行数、选择列、检查缺失值和按时间排序。

## 为什么先 inspect 再分析

文件名不能证明文件里有某个列，也不能证明时间单位是什么。`inspect_dataset` 返回行数、列名、数据类型、前 5 行和缺失值数量，让模型先确认结构，再提供正确的工具参数。

时间列和磁化列都通过参数指定。未来使用 `Time`、`m_z` 等不同列名时，算法仍然可用；未知时间单位会返回 `unknown`，不会猜成 ps。

## switching time 怎么计算

本项目默认找平均磁化第一次从负值达到或穿过零的时间。先确认所选列都是有限数值，将时间排序，再依次检查相邻点 `(t1, m1)`、`(t2, m2)`。满足 `m1 < 0` 且 `m2 >= 0` 时，在两个点之间作线性插值：

```text
t_switch = t1 + (0 - m1) * (t2 - t1) / (m2 - m1)
```

例如 `(1 ps, -0.2)` 和 `(2 ps, +0.2)`，零点在正中间，得到 `1.5 ps`，而不是直接取后一个采样点 `2 ps`。插值减小采样间隔带来的偏差，但不等于知道完整连续曲线。

如果负值之后恰好采到零，直接得到那个零点的时间。如果第一条记录已经是零、后面为正，没有此前负值，程序不把它当成确认的负到正 crossing。重复时间、NaN、非数值、缺列、少于两行或没有 crossing 时会明确报错，避免用不完整信息编造答案。

`positive_to_negative` 可用于反向 crossing。返回结果同时记录相邻点、方向、单位、方法和是否排序，方便核对。

## 模型为什么不能读取整个电脑

模型可以生成错误参数。工具权限如果不受限制，一个路径就可能指向私密文件。这里只允许访问 `data/examples/` 和 `data/local/` 的 CSV：先拒绝绝对路径、UNC 和 `..`，再用 `Path.resolve()` 解析最终路径并检查它仍在允许目录内。这也防止符号链接指向目录外。

Git 忽略 `data/local/`，是为了防止真实数据进入公开仓库。但 Agent 分析时会把检查摘要和工具结果发给 DeepSeek；因此真实数据接入前，用户仍应确认可以把这些信息交给 API。

## 是模型画图还是 Python 画图

模型只输出 `plot_dataset` 的参数，例如 CSV 名、横轴列、纵轴列列表和输出名。Python 使用 matplotlib 读取并绘制曲线，设置坐标、图例、标题和网格，调用 `savefig()` 保存 PNG，最后 `close()` 释放图像。

工具不弹出窗口，也不使用 `plt.show()`。运行图像存放在 `outputs/plots/`，不会自动提交 Git。

## 今天的数据流

```text
用户：比较两条合成曲线的翻转时间
↓
DeepSeek：请求 inspect_dataset
↓
Python：读取 CSV，返回结构摘要
↓
DeepSeek：请求两次 calculate_switching_time
↓
Python：对两列分别找首次零点并插值
↓
DeepSeek：请求 calculator 计算差值
↓
Python：返回数值差
↓
DeepSeek：说明来源、方法、结果和局限
```

一次响应可以请求多个工具，循环也可以连续处理多轮请求。仍然最多调用模型 5 轮，防止无限循环。

示例 CSV 用 `tanh` 生成，101 个采样点。MuMax3、COMSOL 只是演示列的名称，这些数字不能说明真实软件的优劣。LLM 没有亲自打开 CSV、做插值或画图，真正完成这些事情的都是 Python tools。

## Day 3 我真正应该理解的 5 件事

1. 科研答案需要真实读取的数据和可验证的计算，不能只靠文字生成。
2. pandas 用 DataFrame 表示 CSV 表格，便于检查和选择列。
3. 先 inspect 再分析，才能确认列名、单位和缺失值。
4. switching time 由 Python 找首次 crossing 并线性插值，模型负责选择工具和解释结果。
5. 工具只能访问允许目录，合成示例、真实数据和运行输出必须明确区分。
