## 简历匹配词

可真实使用：Python、DeepSeek API、Tool Calling、Agent Loop、pandas、matplotlib、PyMuPDF、TF-IDF、RAG、citation、Streamlit、unittest、holdout evaluation、micromagnetics。

暂时不要写成已掌握：生产级部署、Kubernetes、分布式向量数据库、大模型训练、RLHF、百万级并发。若 JD 需要这些，把它们列入学习计划，不要伪造成项目经验。

## 投递节奏

1. 每周选 20–30 个匹配岗位，不追求无差别海投。
2. 为每类 JD 调整三条 bullet 的顺序，不虚构新经历。
3. 记录岗位、日期、JD 关键词、进度和复盘。
4. 投递前用 3 分钟项目介绍自测；无法解释的词从简历删除或先补课。
5. 不自动投递，不让 Agent 代替本人确认公司、岗位与隐私授权。
